Released the **NeuroClaw** technical report — closed-loop agentic AI for executable and reproducible neuroimaging research (arXiv:2604.24696). NeuroClaw is the harness behind our AI4Neuroscience effort: an agent that plans, runs, and verifies neuroimaging analyses end to end, so that a result arrives with the code that produced it.
